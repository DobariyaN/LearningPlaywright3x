# Prompt Template for IQ Notes

Use this prompt when you want me to create a markdown file explaining a concept in a simple way.

## Prompt

Create a simple markdown file explaining the concept of [TOPIC NAME] in a beginner-friendly way.

Requirements:
- Use simple and easy English.
- Include a short introduction.
- Explain the concept clearly.
- Add a table view if helpful.
- Include one small example.
- Save the file inside the folder named iq_nodes.
- Name the file like: [TOPIC_NAME]_IQ.md

## Example

Create a simple markdown file explaining the concept of "source code, bytecode, and binary code" in a beginner-friendly way.

Requirements:
- Use simple and easy English.
- Include a short introduction.
- Explain the concept clearly.
- Add a table view.
- Include one small example.
- Save the file inside the folder named iq_nodes.
- Name the file like: Source_Code_ByteCode_Binary_IQ.md
